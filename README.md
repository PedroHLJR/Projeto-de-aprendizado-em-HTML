# 🌐 Projeto Final HTML — Portfólio Pessoal

> Meu primeiro projeto em HTML. Desenvolvido como trabalho final do curso de HTML.

---

## 🎯 Sobre o projeto

Este foi o **primeiro site que desenvolvi**, criado como trabalho final do curso de HTML.  
É um portfólio pessoal simples com seções de apresentação, sobre mim, projetos e contato.

O projeto marca o ponto de partida da minha jornada no desenvolvimento web.

---

## ✅ O que foi praticado

- Estrutura básica de um documento HTML (`DOCTYPE`, `<head>`, `<body>`)
- Tags semânticas: `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`
- Navegação com âncoras (`href="#secao"`)
- Atributo `alt` em imagens para acessibilidade
- CSS externo separado do HTML
- Estilização de cards, cabeçalho e rodapé
- Links clicáveis com `mailto:` e `tel:`
- Meta tag `viewport` para responsividade mobile
